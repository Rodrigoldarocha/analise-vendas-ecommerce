# 🛒 Análise de Vendas de E-commerce

## 📌 Sobre o projeto

Neste projeto, eu realizei uma análise exploratória de dados (EDA) em um dataset de vendas de e-commerce, com o objetivo de extrair insights relevantes para o negócio.

A ideia foi simular um cenário real onde um analista de dados precisa entender o desempenho de produtos e categorias.

---

## 🎯 Objetivos

- Analisar o faturamento total
- Identificar os produtos mais vendidos
- Avaliar o desempenho por categoria
- Entender o comportamento das vendas ao longo do tempo

---

## 🧠 Habilidades desenvolvidas

- Manipulação de dados com Pandas
- Análise exploratória (EDA)
- Criação de visualizações com Matplotlib e Seaborn
- Geração de insights de negócio

---

## 🛠️ Tecnologias utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

---

## 📊 Principais análises

Durante o projeto, eu:

- Calculei o faturamento total da operação
- Identifiquei os produtos mais vendidos
- Analisei o faturamento por categoria
- Visualizei a evolução das vendas ao longo do tempo

---

## 📈 Exemplos de insights

- Alguns produtos concentram a maior parte das vendas
- A categoria "Eletrônicos" domina o faturamento
- Existem variações ao longo do tempo que podem indicar sazonalidade
